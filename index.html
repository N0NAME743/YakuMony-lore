Context Primer — 公開版・読み込み用ドキュメント

YakuMony-Lore

ChatGPT / Gemini など、別のAIサービスとの相談を始めるときに渡すための前提情報です。デバイス構成・稼働中のプロジェクト・運用ルールを、公開して差し支えない範囲でまとめています。

※このページはYAKUMOのキャラクター設定書ではありません。YAKUMOはN0NAMEが運用するキャラクターIPで、X自動投稿システムはその運用手段の一つです。キャラクター設定そのものは別資料で管理しています。

最終更新 2026-09-23 個人開発 / ソロ運用 完全公開ページ(bot読み込み可)

最短で伝えたいこと

  • 拠点は GitHub の development リポジトリ ひとつ。複数プロジェクトをフォルダで分けて運用
  • 本番稼働中のものは YAKUMO の X 自動投稿システムのみ。他は開発中/実験中
  • Notion に別のパイプライン(リサーチ→裏取り→IDEA BOX→公開サイト)が動いている
  • 作成した資料は Google Drive の受け箱フォルダに保存する運用
  • 個別プロジェクトの深い話が必要なら、別途詳細を渡す

03

Notion INBOXパイプライン

development リポジトリとは別に、Notion 側で「集めて→精査して→公開する」ための情報整理パイプラインが稼働中。各DBに「AI自動」「手動」のタグを付けている。

記録_Memo手動
投資・ツール・本・ゲーム・日記など、雑多なメモの置き場。すべて自分で書いて追記する。
記録_AI To Notion手動
YAKUMO プロジェクトのメモなど。名前に反して自動化はされていない。
記録_Research INBOXAI自動
SNS(X)の投稿を自動収集し、出どころのタグ付けと一次判定まで自動で入る。
記録_裏取りレポート・根拠AI自動
Research INBOX の内容をAIが検証し、判定結果を自動で記録する。
IDEA BOXAI自動
裏取りを終えた知見の最終置き場。要約・評価まで AI が自動生成する。公開サイトの元ネタになる。

Research INBOX(AI自動) → AI査定・裏取り(AI自動) → IDEA BOX(AI自動) → 公開サイト

04

アップロード先

仕様書・引き継ぎ資料などをこの場で作ってもらった場合、そのまま渡せる置き場が Google Drive にある。

Google Drive「BasecampInbox」受け箱
作成した資料(仕様書・引き継ぎメモ・コード等)は、テキストとして出力してもらえれば、こちらでこのフォルダに保存する。フォルダへの直接リンクはこのページには載せていない(保存は本人が行う)。
05

運用ルール

  • フォルダ命名: 新設フォルダは英語 snake_case に統一
  • 言語: 会話・仕様書は日本語、コード・変数名・新規ディレクトリ名は英語
  • 機密情報厳禁: APIキー・トークン・個人を特定できる情報は、コード/ドキュメント/このページのどこにも書かない
06

このページの使い方

  1. ChatGPT / Gemini など、他のAIサービスで新しい相談を始めるとき、まずこのリンクを渡す(このページは公開HTMLなので、AIの自動読み込みにも対応している)
  2. 仕様書・引き継ぎ資料などを作ってもらったら、コピーできる形(テキスト/Markdown等)で出力してもらう。保存自体は本人が「04 アップロード先」に対応する場所へ行う
  3. 環境やプロジェクト構成が変わったら、Claude Code セッションでこのページの更新を依頼する。内容の最終確認は本人が行う
  4. Claude Code 向けの、より詳しい実務情報は別の非公開ページに置いている
07

AIへの指示

  • 情報が競合したら「実際のコード/設定 > 非公開の詳細仕様 > このページ > AIの推測」の順で優先する
  • 作業対象プロジェクトを指定されたら、まずそのディレクトリの README・spec・設定ファイルを確認してから提案する
  • Project_YAKUMO など本番稼働中のシステムに対し、停止・削除・DB変更・認証変更などの不可逆操作は、明示的な確認なしに行わない
  • 基本ブランチは main。コミット/push を AI 自身が実行してよいかは、その都度人に確認する
